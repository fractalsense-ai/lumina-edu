# Education Foundation Model-Pack

Shared education foundation pack for department education model-packs.

This pack contains reusable state schemas, monitoring utilities, and reference
specifications extracted from the original monolithic education pack. It is not
intended as a learner-facing domain.

## Owns

- Shared schemas under `schemas/`
- Shared monitoring utilities under `domain-lib/monitoring/`
- Shared turn/reference specifications under `domain-lib/reference/`
- The `domain/eduf/foundation-core/v1` boundary physics

## Does Not Own

- Math curriculum or problem generation
- Student Commons/journaling policy
- Teacher, teaching-assistant, or domain-authority workflows
- World-sim presentation templates
