# Student Commons

Active Student Commons ownership has moved to the education-commons pack:
[`model-packs/education-commons/docs/7-concepts/student-commons.md`](../../../education-commons/docs/7-concepts/student-commons.md)

The legacy `education` pack keeps `general-education` only as a compatibility
module for older `domain/edu/general-education/v1` references during the
model-pack cutover. Safe journaling, vocabulary-growth APIs, Safe Person
workflow, and the active Student Commons runtime are owned by
`education-commons`.
